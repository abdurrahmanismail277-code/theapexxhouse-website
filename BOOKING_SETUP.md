# Payment flow

The booking page collects service and event details for review in the visitor's browser. After review, it shows the NGN bank transfer instructions and copy buttons. The page does not send a booking request to the server or send booking emails.

For fixed-price virtual services, the payment screen shows the exact total and a generated payment narration. Physical moderation and Launch Hosting require a final quote; visitors are directed to WhatsApp to confirm the amount.

After paying, visitors can use the WhatsApp confirmation link on the payment screen to share their service, event, payment reference, and receipt. The CAPTCHA and booking API are currently disabled. Re-enable server submission and CAPTCHA verification before using automatic booking emails again.
